# 易文本（YiText）

易文本是一种以**中文为基础**的轻量级标记语言，灵感来自 Markdown，但语法全部用中文拼音首字母，写中文内容时更顺手、更好记。

```text
yi 一级标题
jc 加粗的内容
yy 引用的内容
wxlb 无序列表项
```

本项目提供一个**零依赖、纯 HTML** 的实时预览编辑器 `ywb-editor.html`：左侧写语法，右侧实时渲染，开箱即用。

## ✨ 特性

- 左写右预览，输入即渲染（120ms 防抖）
- 全套中文语法：标题、加粗、斜体、下划线、高亮、删除线、引用、列表、代码块、提示框、折叠、脚注……
- `.ywb` 文档导入 / 导出（本质就是 UTF-8 纯文本）
- 一键导出 HTML、复制 HTML 源码
- 明暗主题切换、可拖动分隔条、本地自动保存
- 🎤 语音输入（Web Speech API，Chrome / Edge 支持）

## 🚀 快速开始

直接用浏览器打开 [`ywb-editor.html`](ywb-editor.html) 即可，无需安装或构建。

- 点「✨ 载入示例」查看所有语法效果
- 点「📖 语法速查」查看完整对照表
- 点「💾 导出 .ywb」保存你的文档
- 点「📂 导入 .ywb」载入已有文档

## 📖 语法速查

> 通用规则：行首写「语法词 + 空格 + 内容」即生效。

### 标题

| 语法 | 效果 |
| --- | --- |
| `yi 内容` | 一级标题 |
| `er 内容` | 二级标题 |
| `san 内容` | 三级标题 |
| `si 内容` | 四级标题 |
| `wu 内容` | 五级标题 |
| `liu 内容` | 六级标题 |

超过六级（如 `qi`、`ba` …）按六级标题处理。

### 文本样式

| 功能 | 语法 | 说明 |
| --- | --- | --- |
| 加粗 | `jc 内容` | 整行加粗 |
| 斜体 | `xt 内容` | 整行斜体 |
| 下划线 | `xhx 内容` | |
| 高亮 | `gl 内容` | 荧光笔效果 |
| 删除线 | `scx 内容` / `sc 内容` | 两种写法等价 |
| 引用 | `yy 内容` | |
| 行内代码 | `hndm 内容` | |
| 上标 | `sb 内容` / `sjb 内容` | 两种写法等价 |
| 下标 | `xb 内容` / `xjb 内容` | 两种写法等价 |
| 颜色 | `ys#ff0000 内容` / `ys255,0,0 内容` | 整行着色，支持十六进制 `#rgb/#rrggbb` 或 `r,g,b` 写法 |
| 字号 | `zh1 内容` / `zh2 内容`（及 `zh`+数字） | 整行放大，数字越大字越大 |

### 列表

| 语法 | 效果 |
| --- | --- |
| `wxlb 内容` / `d 内容` | 无序列表（连续多行自动合并）；`d` 取「点」的首字母，对应无序号的项目符号 |
| `yxlb 内容` | 有序列表（连续多行自动合并） |
| `rw 内容` | 任务列表（带复选框，连续多行自动合并） |

### 代码块

单独一行 `dmk`（或 `dm`）开始，再单独一行 `dmk`（或 `dm`）结束；可用 `dmk 语言` 标注语言（如 `dmk js`）。

```text
dmk
function hello(name) {
  console.log("你好，" + name);
}
dmk
```

### 提示框

`tsk 内容` 为默认提示；可选类型：`tsk info | success | warn | danger 内容`。

```text
tsk 这是一条普通提示
tsk warn 这是一条需要注意的警告
```

### 折叠内容

`zdnr 标题`（或 `zd 标题`）开始，`zdnr`（或 `zd`）单独一行结束，中间多行为折叠正文。

```text
zdnr 点击展开：更多说明
这里是可以放补充说明的长段落。
支持多行内容。
zdnr
```

### 分隔与结构

| 语法 | 效果 |
| --- | --- |
| `fgx` | 分割线 |
| `---` | 单实线（整行输入后回车） |
| `===` | 双实线（整行输入后回车） |
| `···` | 虚线（整行输入后回车） |
| `～～～` | 波浪线（整行输入后回车） |
| `hh` | 换行（插入空行间距） |
| `fy` | 分页（虚线分页标记） |
| `ml` | 目录（自动收集此前所有标题） |
| `sj` | 时间戳（插入当前时间，随编辑更新） |

### 对齐

| 语法 | 效果 |
| --- | --- |
| `jzuo 内容` / `kz 内容` | 居左 |
| `jzong 内容` / `zj 内容` | 居中 |
| `jyou 内容` / `ky 内容` | 居右 |

### 链接与媒体

| 功能 | 语法 | 说明 |
| --- | --- | --- |
| 普通链接 | `lj 显示文字|网址` | 无 `\|` 时整段作为网址 |
| 图片 | `tplj / tclj / zplj 替代文字|图片地址` | 三种写法等价 |
| 视频 | `splj 说明|视频地址` | 自带播放器 |
| 音频 | `yplj 说明|音频地址` | 自带播放器 |
| 附件 | `fjlj 文件名|文件地址` | |

### 脚注

`jz 脚注内容` 自动编号，文末汇总并支持点击跳转。

### 表格

表格使用 **Markdown 管道语法**（仅表格沿用 Markdown，其余语法不变）。

- **第一行 = 表头**：用 `|` 分隔各列。
- **第二行 = 分隔行**：用 `---` 分隔，可加 `:` 设置对齐（`---` 左对齐、`:---:` 居中、`---:` 右对齐）。
- **后续行 = 数据行**：同样用 `|` 分隔各列。

```text
| 列1 | 列2 | 列3 |
|------|------|------|
| 内容 | 内容 | 内容 |
```

上面三行渲染成一张三列表格：表头「列1 / 列2 / 列3」，下面一行数据。

设置对齐的示例：

```text
| 左对齐 | 居中 | 右对齐 |
|:------|:----:|------:|
| a     | b   | c     |
```

> 注：早期版本曾用过 `bg ` 前缀和 `<bgh>` / `<bglN>` 标签两种表格语法，均已废弃，请统一改用上面的 Markdown 管道语法。

### 竖排

用 `shu` 开启竖排、`heng` 恢复横排（区块式）：

- `shu` = 竖排，**默认从右到左**（中文传统）；`shu zuo` = 从左到右
- 区块内**每一行 = 一列**
- **标点自动贴在字下方**，数字 / 英文自动横向显示

```text
shu
床前明月光，
疑是地上霜。
举头望明月，
低头思故乡。
heng
```

## 📄 文件格式 .ywb

`.ywb` 就是易文本源码的 UTF-8 纯文本文件，可用本编辑器导入 / 导出，也可用任意文本编辑器打开。导出 HTML 时会自动生成一份带样式的独立网页。

## 📦 给其他开发者（集成库）

如果你要在**自己的网站 / 应用里识别并渲染易文本**，不用自己写解析器——直接用我们抽离的独立库：

- **`yitext.js`**：零依赖 UMD 库，浏览器 `<script>` 或 Node `require` 都能用，暴露 `YiText.parse(src, options)`。
- **[`集成与使用文档.md`](./集成与使用文档.md)**：面向开发者的接口文档，含"其他网站如何识别易文本"的约定与探测方案、浏览器/Node/前端框架/服务端示例、安全说明。
- **[`语法速查表.md`](./语法速查表.md)**：完整语法对照表，可直接发给用户或协作者学习。

```js
const YiText = require('./yitext.js');
const html = YiText.parse(yourYiText, { css: true }); // css:true 自动带默认样式
```

## 🚀 发版

项目内置了一键发版脚本，会自动完成「同步库版本号 → 提交 → 推送 → 打 tag → 创建 Release」全流程：

```bash
./release.sh v0.3.0 "本次版本说明"
```

- 版本号格式：`v主.次.修订`（如 `v0.3.0`）
- 依赖：已安装 `gh` CLI 并登录（`gh auth login`）
- 说明文字会作为 GitHub Release 的正文
