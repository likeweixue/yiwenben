# 易文本（YiText）

易文本是一种以**中文为基础**的轻量级标记语言，灵感来自 Markdown，但语法全部用中文拼音首字母，写中文内容时更顺手、更好记。

```text
yi 一级标题
jc 加粗的内容
yy 引用的内容
wxlb 无序列表项
```

本项目提供一个**零依赖、纯 HTML** 的实时预览编辑器 `ywb-editor.html`：左侧写语法，右侧实时渲染，开箱即用。

## ✨ 特性

- 左写右预览，输入即渲染（120ms 防抖）
- 全套中文语法：标题、加粗、斜体、下划线、高亮、删除线、引用、列表、代码块、提示框、折叠、脚注……
- `.ywb` 文档导入 / 导出（本质就是 UTF-8 纯文本）
- 一键导出 HTML、复制 HTML 源码
- 明暗主题切换、可拖动分隔条、本地自动保存
- 🎤 语音输入（Web Speech API，Chrome / Edge 支持）

## 🚀 快速开始

直接用浏览器打开 [`ywb-editor.html`](ywb-editor.html) 即可，无需安装或构建。

- 点「✨ 载入示例」查看所有语法效果
- 点「📖 语法速查」查看完整对照表
- 点「💾 导出 .ywb」保存你的文档
- 点「📂 导入 .ywb」载入已有文档

## 📖 语法速查

> 通用规则：行首写「语法词 + 空格 + 内容」即生效。

### 标题

| 语法 | 效果 |
| --- | --- |
| `yi 内容` | 一级标题 |
| `er 内容` | 二级标题 |
| `san 内容` | 三级标题 |
| `si 内容` | 四级标题 |
| `wu 内容` | 五级标题 |
| `liu 内容` | 六级标题 |

超过六级（如 `qi`、`ba` …）按六级标题处理。

### 文本样式

| 功能 | 语法 | 说明 |
| --- | --- | --- |
| 加粗 | `jc 内容` | 整行加粗 |
| 斜体 | `xt 内容` | 整行斜体 |
| 下划线 | `xhx 内容` | |
| 高亮 | `gl 内容` | 荧光笔效果 |
| 删除线 | `scx 内容` | |
| 引用 | `yy 内容` | |
| 行内代码 | `hndm 内容` | |
| 上标 | `sb 内容` | |
| 下标 | `xb 内容` | |

### 列表

| 语法 | 效果 |
| --- | --- |
| `wxlb 内容` | 无序列表（连续多行自动合并为一个列表） |
| `yxlb 内容` | 有序列表（连续多行自动合并） |

### 代码块

单独一行 `dmk` 开始，再单独一行 `dmk` 结束；可用 `dmk 语言` 标注语言（如 `dmk js`）。

```text
dmk
function hello(name) {
  console.log("你好，" + name);
}
dmk
```

### 提示框

`tsk 内容` 为默认提示；可选类型：`tsk info | success | warn | danger 内容`。

```text
tsk 这是一条普通提示
tsk warn 这是一条需要注意的警告
```

### 折叠内容

`zdnr 标题` 开始，`zdnr` 单独一行结束，中间多行为折叠正文。

```text
zdnr 点击展开：更多说明
这里是可以放补充说明的长段落。
支持多行内容。
zdnr
```

### 分隔与结构

| 语法 | 效果 |
| --- | --- |
| `fgx` | 分割线 |
| `hh` | 换行（插入空行间距） |
| `fy` | 分页（虚线分页标记） |
| `ml` | 目录（自动收集此前所有标题） |
| `sj` | 时间戳（插入当前时间，随编辑更新） |

### 对齐

| 语法 | 效果 |
| --- | --- |
| `jzuo 内容` | 居左 |
| `jzong 内容` | 居中 |
| `jyou 内容` | 居右 |

### 链接与媒体

| 功能 | 语法 | 说明 |
| --- | --- | --- |
| 普通链接 | `lj 显示文字|网址` | 无 `\|` 时整段作为网址 |
| 图片 | `tplj 替代文字|图片地址` | |
| 视频 | `splj 说明|视频地址` | 自带播放器 |
| 音频 | `yplj 说明|音频地址` | 自带播放器 |
| 附件 | `fjlj 文件名|文件地址` | |

### 脚注

`jz 脚注内容` 自动编号，文末汇总并支持点击跳转。

## 📄 文件格式 .ywb

`.ywb` 就是易文本源码的 UTF-8 纯文本文件，可用本编辑器导入 / 导出，也可用任意文本编辑器打开。导出 HTML 时会自动生成一份带样式的独立网页。
